# Video Summarizer & Transcriber

YouTube captions or local Whisper transcription → summary, key points, timestamped chapters, quotes, action
items, study notes and a full transcript. Map-reduce over transcript chunks so long videos fit a local model.
Setup and usage: [docs/user-guide/video-summarizer.md](../../docs/user-guide/video-summarizer.md).

`sample_transcripts/reliable-agents-talk.json` is a synthetic 4-minute talk used by the evaluation suite
(`{"source": "fixture:reliable-agents-talk", "dry_run": true}`).
